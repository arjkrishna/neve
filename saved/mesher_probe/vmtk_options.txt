== vmtkcenterlines
   compute centerlines from a branching tubular surface (see papers for details); seed points can be interactively selected on the surface, or specified as the barycenters of the open boundaries of the surface; if vmtk is compiled with support for TetGen, TetGen can be employed to compute the Delaunay tessellation of the input points
   Id                           str      default=0             script id
   Self                         self     default=<vmtk.vmtkce  handle to self
   Disabled                     bool     default=0             disable execution and piping
   SurfaceInputFileName         str      default=              filename for the default Surface reader
   SeedSelectorName             str      default=pickpoint    range=["pickpoint","openprofiles","carotidprofiles","profileidlist","idlist","pointlist"]  seed point selection method (pickpoint: interactive; openprofiles: choose among barycenters of open profiles of the surface; carotidprofiles: open profiles are automatically selected based on their z-axis coordinate (lower to higher: CCA, ECA, ICA)); profileidlist: list of open profile ids (specified as argument to -sourceids and -targetids); idlist: list of surface point ids (specified as argument to -sourceids and -targetids); pointlist: list of surface points (specified as argument to -sourcepoints and -targetpoints)
   SourceIds                    int      default=[]            list of source point ids
   TargetIds                    int      default=[]            list of target point ids
   SourcePoints                 float    default=[]            list of source point coordinates
   TargetPoints                 float    default=[]            list of target point coordinates
   AppendEndPoints              bool     default=0             toggle append open profile barycenters to centerlines
   CheckNonManifold             bool     default=0             toggle checking the surface for non-manifold edges
   FlipNormals                  bool     default=0             flip normals after outward normal computation; outward oriented normals must be computed for the removal of outer tetrahedra; the algorithm might fail so for weird geometries, so changing this might solve the problem
   CapDisplacement              float    default=0.0           displacement of the center points of caps at open profiles along their normals (avoids the creation of degenerate tetrahedra)
   DelaunayTolerance            float    default=0.001         tolerance for evaluating coincident points during Delaunay tessellation, evaluated as a fraction of the bounding box
   RadiusArrayName              str      default=MaximumInscr  name of the array where radius values of maximal inscribed spheres have to be stored
   AppendEndPoints              bool     default=0             toggle append open profile barycenters to centerlines
   Resampling                   bool     default=0             toggle centerlines resampling
   ResamplingStepLength         float    default=1.0          range=(0.0,)  distance between points in the resampled line
   DelaunayTessellation         vtkUnstructuredGrid default=None          optional input Delaunay tessellation
   SimplifyVoronoi              bool     default=0             toggle simplification of Voronoi diagram
   UseTetGen                    bool     default=0             toggle use TetGen to compute Delaunay tessellation
   TetGenDetectInter            bool     default=1             TetGen option
   CostFunction                 str      default=1/R           specify cost function to be minimized during centerline computation
   vmtkRenderer                 vmtkRenderer default=None          external renderer
   PoleIds                      vtkIdList default=None          
   VoronoiDiagram               vtkPolyData default=None          
   VoronoiDiagramInputFileName  str      default=              filename for the default VoronoiDiagram reader
   StopFastMarchingOnReachingTarget bool     default=0             terminate fast marching front propagation when the front reaches the target seed point. This can greatly speed up execution, but it only works when one target seed id is set.
   CenterlinesOutputFileName    str      default=              filename for the default Centerlines writer
   DelaunayTessellationOutputFileName str      default=              filename for the default DelaunayTessellation writer
   VoronoiDiagramOutputFileName str      default=              filename for the default VoronoiDiagram writer
